# Blueprint visual language

The deep navy canvas presents diagrams as engineering notes. Warm paper is a second treatment of the same semantic system. IBM Plex Sans carries the explanation; Plex Mono labels parts and measurements. Pale lines establish structure, muted blue recedes, and amber marks one relationship or state at a time.

Use the grid as a quiet spatial reference. Give a diagram whitespace and a single reading direction. Reveal a connector after its source appears; reveal a node when the connection reaches it. Prefer measured labels, line drawing, controlled wipes, and brief camera pushes. The [Git history film](../../examples/blueprint/git_history.py) is the reference treatment.

Tokens live in `motion.style`: `blueprint` and `blueprint-paper`. Keep content independent from those token names so the same graph or process can use either treatment.
