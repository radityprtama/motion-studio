| Source | What it teaches |
| --- | --- |

| `blueprint/request_flow.py` | Vertical device flow, directed connector, safe caption |
| `cinematic/atmospheric_title.py` | Lit orb, particles, dark composition |
| `cinematic/crowd_statistic.py` | Deterministic crowd, proportion highlight, scale |
| `cinematic/object_grid.py` | Seeded component repetition and one controlled focus |
| `portrait/statistics_composition.py` | Semantic statistic pattern, values and headline on a portrait canvas |

Each source exports an editable `scene`. Use `motion inspect` for representative stills and `motion preview` for timing. Source and sample stills for four reusable treatments also live in `memory/scenes/`.
